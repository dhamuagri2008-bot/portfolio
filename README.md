# Portfolio

A clean, responsive personal portfolio website built with semantic HTML, modern CSS, and a tiny JavaScript menu.

## Run locally

Open `index.html` in a browser. No build step or dependencies are required.

## Customize

- Replace the placeholder name/content in `index.html`.
- Update project cards and links.
- Change the email address in the contact section.
- Adjust colors and typography in `style.css`.

## Deploy

This is a static site and can be deployed with GitHub Pages or any static hosting provider.
